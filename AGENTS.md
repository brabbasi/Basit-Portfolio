# Basit Portfolio — Agent Instructions

## Marketech independent Reviewer — mandatory gate

This portfolio is a **Tier-2 public-facing project** enrolled in the central JARVIS / Marketech independent Reviewer fabric.

- Material code/content, résumé/project/employment/education/certification claims, public contact details, external links, analytics/tracking and production deployment changes require an independent exact-head review record before consequential promotion.
- The producing agent may prepare evidence and deterministic checks but may not self-approve its own material work.
- Reviewer execution belongs to the central Marketech Reviewer / Trusted runtime. Do not create a duplicate per-repository hosted GitHub Action or repository-local Reviewer secret path.
- Missing, quota-rejected, stale-head or infrastructure-only review evidence is not approval.
- Review must verify factual public claims, privacy, accessibility, broken links/assets, responsive behavior, metadata/SEO and deployment integrity.
- Never fabricate employers, projects, certifications, metrics, testimonials, skills or outcomes.
- Do not expose private contact/account information unless intentionally approved for public display.
- A review verdict alone does not authorize public production deployment.

See `.marketech/reviewer.json` and `.marketech/BASELINE_REVIEW.md`.
